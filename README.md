# 음식점 목표매출 계산기 (2차 시제품)

## 파일 구성
- `index.html`: 한 페이지 안에서 3단계 화면을 전환하는 구조
- `style.css`: 하늘색 배경, 결과 카드, 마라톤 트랙, 달리는 캐릭터 애니메이션 및 모바일 반응형 디자인
- `script.js`: 단계 이동, 목표 매출 계산, 트랙 눈금과 결과 자동 연동

## 실행 방법
1. ZIP 파일을 다운로드한 뒤 압축을 풉니다.
2. `index.html`을 더블클릭해 브라우저에서 엽니다.
3. 1단계에서 원하는 월 이익을 입력합니다.
4. 2단계에서 가게 정보를 입력합니다.
5. 3단계에서 목표 매출과 마라톤 트랙을 확인합니다.

## GitHub Pages
`index.html`, `style.css`, `script.js`를 GitHub 저장소 최상위 폴더에 업로드한 뒤 `Settings → Pages`에서 배포합니다.

## 계산 기준
- 손익분기점 월 매출 = 월 고정 지출 ÷ (1 − 매출에 따라 늘어나는 비용 비율)
- 목표 월 매출 = (월 고정 지출 + 목표 월 이익) ÷ (1 − 매출에 따라 늘어나는 비용 비율)
- 현재 예상 월 매출 = 평균 결제금액 × 현재 하루 평균 손님 수 × 월 영업일수
- 하루 필요 손님 수 = 목표 일 매출 ÷ 평균 결제금액

현재 하루 손님 수는 선택 항목입니다. 결과는 입력값에 따른 예상치이며 사업주 인건비, 세금, 대출이자 등을 고정 지출에 포함했는지에 따라 실제 이익은 달라질 수 있습니다.
